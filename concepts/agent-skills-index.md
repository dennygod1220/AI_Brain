# Agent Skills Index

## 用途一覽

| Skill 名稱 | 用途 |
|---|---|
| **arxiv** | 搜尋並取得 arXiv 學術論文（關鍵字、作者、分類、ID），不需 API Key |
| **blogwatcher** | 監控部落格與 RSS/Atom 訂閱來源的新文章更新 |
| **huggingface-model-browsing** | 瀏覽 HuggingFace 模型頁面，處理截斷清單、量化版本比較 |
| **llm-wiki** | 建立並維護 Karpathy LLM Wiki 風格的 interconnected markdown 知識庫 |
| **polymarket** | 查詢 Polymarket 預測市場資料（價格、訂單簿、歷史），唯讀 API |
| **reddit-json-api-scraper** | 使用 Reddit JSON API 取代 browser 爬取內容，速度快、資料完整 |
| **reddit-ai-trend-monitor** | 自動化掃描 r/LocalLLaMA、r/MachineLearning、r/AI_Insights 三大版塊，產出結構化趨勢報告 |
| **research-paper-writing** | ML/AI 研究論文寫作完整流程（實驗設計→分析→草稿→修訂→投稿） |
