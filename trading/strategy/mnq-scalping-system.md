# MNQ Scalping System — Strategy Reference

> Micro E-mini Nasdaq-100 Futures，3分K，手機交易。
> 更新：2026-04-30（Train Mode 🚃 加入）

---

## 一、圖表配置 (手機TradingView)

### 主圖指標

| 指標 | 週期 | 顏色 | 角色 |
|:----:|:----:|:----:|------|
| **EMA10** | 10 | 🔵 青 (teal) | **快線 / 拖曳停損**：TP1後掛SL在此下方 |
| **EMA30** | 30 | 🟡 黃 | **中線 / 趨勢判定**：價格在上=多頭結構完整 |
| **EMA60** | 60 | 🟣 紫 | **慢線 / 結構破壞**：跌破=趨勢可能反轉 |
| **VRVP** | — | 淺藍 | 高量節點(黃線POC) = 支撐/壓力參考 |

### 副圖指標

| 指標 | 用途 | 關鍵閾值 |
|:----:|------|:---------:|
| **KDJ** | 進場觸發 | J過熱>105，超賣<0~-5，交叉才是訊號 |
| **ADX(14)** | 趨勢強度濾網 | DI gap>10=有方向，gap<5=盤整 |

> ⚠️ **EMA10與EMA30差距 <10pt = 弱支撐**，快中線靠太近時一次就被突破

## 二、進場篩選層級 (Priority Order)

```
1️⃣ KDJ 黃金/死亡交叉 — 先行指標 (觸發器)
2️⃣ ADX DI 交叉 + 交叉線 > 20 — 確認濾網
3️⃣ DI+ / DI- 差距 > 10 — 方向性確認
4️⃣ 15分K KDJ 方向一致 — 高時間級別過濾
5️⃣ EMA 結構 — 價格在 EMA30 之上(多) / 之下(空)
```

### 🟢 做多 (Long)

1. KDJ 黃金交叉 (J上穿K/D)
2. ADX DI+ > DI- 且 DI+ > 20
3. DI gap > 10
4. 15分K J 值上升中
5. 價格在 EMA30 上方

### 🔴 做空 (Short)

1. KDJ 死亡交叉 (J下穿K/D)
2. ADX DI- > DI+ 且 DI- > 20
3. DI gap > 10
4. 15分K J 值下降中
5. 價格在 EMA30 下方

### J值進場時機表

| J值區間 | 動能階段 | 操作 |
|:-------:|:--------:|:----:|
| **50-85** ↗️ | ✅ 甜蜜區，新鮮動能 | 正常進場 |
| **20-50** | 🟡 動能中段 | 進場但預期跑不遠 |
| **<20** ↘️ | ❌ 動能耗盡 | **等** — 模式可能已過時 |
| **>100** 🚀 | 🟡 接近耗竭 | 進場但縮小目標 |

## 三、兩口拆分 + Train Mode 🚃

### 初始設置

| 項目 | 數值 |
|:----|:----|
| 進場 | 2口同價位 |
| 初始停損 | 至少 **15-20pt** (<10pt太緊會被noise刷掉) |
| R:R | 至少 1:1（近期波動大，先求勝率） |

### Phase 1：TP1 鎖利

- 目標：心理關口或阻力位 (~9-15pt)
- ✅ 第一口平倉，利潤入袋
- 立刻調整剩餘口數的停損

### Phase 2：Train Mode 🚃 (第二口)

TP1後，剩餘一口進入 **Train Mode**：

**持倉條件 (全須符合):**
- ✅ 價格在 **EMA10** 上方（快線沒破 = 動能仍在）
- ✅ 價格在 **EMA30** 上方（中線沒破 = 趨勢健康）
- ✅ ADX DI gap > 10（趨勢未消散）

**出場條件 (任一觸發即出):**

| 優先級 | 條件 | 動作 |
|:------:|------|:----:|
| 🅰️ | 價格跌破 **EMA10** | 🚨 立即出場 |
| 🅱️ | KDJ死亡交叉 + DI gap腰斬 | ⚠️ 出場 |
| 🅲 | DI gap < 5 | 📉 趨勢消散，出場 |
| 🅳 | EMA30 被測試 | 🔍 考慮出場 |

**J值過熱覆蓋規則：**
```
當 ADX DI gap > 20：
  → J 值過熱 (>105) 忽略
  → J 值加速 (20→90+ <30min) 忽略
  → 唯一信號：EMA10跌破 或 KDJ死亡交叉+DI gap腰斬
```

### Train Mode 示意圖

```
進場 27,299.5 (2口)
  │
  ├─ TP1 27,325.5 (+26pt) ✅ ─── 利潤鎖住
  │
  └─ Train Mode 🚃 ── SL掛EMA10下方
       │
       ├─ 價格衝 27,520 🚀 ── EMA10跟著追高
       │
       ├─ 價格回落破EMA10 ── 🚨 出場 ~27,440
       │
       └─ +140-160pt ✅ (vs 手動J值出場+84pt)
```

## 四、盤整日辨識 (Chop Day)

以下 **3項以上** 同時發生 = 盤整日，**0口** 或最多 **1口**：

1. ✅ 價格區間 60-100pt 未突破
2. ✅ KDJ 超賣↔超買往返 ≥ 2 次
3. ✅ EMA10 與 EMA30 差距 < 10pt
4. ✅ 多次假突破 (無 HH/HL 或 LH/LL)
5. ✅ 亞洲盤 (08:00-12:00) 持續低量

|:----|:----:|

| DI gap < 5 或 15分KDJ方向不一致 | **1口或0口** ⚠️ |
| 盤整日 3+ 信號 | **0口** 🛑 |
| 剛被停損後 (15-30分內) | **最多1口** 🔄 |
| 大賺後下一筆 | **嚴格審查** 🔍 |

## 六、原則 (手機速記)

1. ❌ 不追價 — 等回調到EMA區
2. ✅ 進場前設好 SL + TP
- ✅ R:R 至少 1:1
4. ✅ 獲利 50% 後考慮推停損
5. ❌ 不逆強勢進場
6. ⚠️ 大賺後 → 下一筆標準放寬，有猶豫就不進
7. 🔄 被停損後 → 不要立刻進，等 15-30分
8. 🚨 **結構破壞 = 出場** — 停損線是備用，EMA結構被破壞才是真正出場信號
