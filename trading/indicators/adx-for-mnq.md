# ADX 盤整過濾 + 多時間框架

> 2026-04-29 開發心得 + 修正記錄（v2）。
> 第一版 v1 犯了一個錯誤：用教科書的 ADX 閾值（<20=盤整）套到 3分K MNQ，但實際上 MNQ 在 3分K 上 ADX 長期在 25-40 之間，
> 即使亞洲盤盤整日也是如此。ADX 的應用需要重新校正。

---

## 問題：為什麼 KDJ 在盤整日會失效？

KDJ 是動能指標（momentum oscillator），它的運作邏輯是「漲太多會跌、跌太多會漲」。但在 **區間震盪** 時：
- 超賣區 J<5 → 反彈幾點就熄火
- 超買區 J>95 → 回跌幾點就撐住
- golden cross 和 death cross 反覆出現

不是 KDJ 壞了，是 **市場沒有趨勢——順勢交易本來就不該進場**。

---

## 📌 重要校正（v2）：ADX 在 3分K MNQ 的真實行為

### 4/29 實際數據

10:20 截圖顯示：
- **ADX（黃線）：22.99**
- **DI+（綠線）：29.36**（多頭動能強）
- **DI-（紅線）：15.68**

**實際 ADX 在早上更高：~35 左右。**

### 為什麼 ADX=35 但亞洲盤還是盤整？

ADX 在 3分K MNQ 上有幾個特性：

1. **MNQ 本身波動大** — 3分K 的單根 K 棒動不動 5-15pt，這在 ADX 運算上就會推高數值
2. **ADX 是滯後指標** — 一根 30pt 的大 push（如今天 O/N 從 27,093→27,294），會讓 ADX 維持在高檔很久，即使後面開始盤整
3. **ADX 高 ≠ 保證不盤整** — 它只說「過去 N 根 K 有過大波動」，不代表接下來不會盤

### 4/29 的真相

```
O/N 時段：27,093 → 27,294（+200pt 大趨勢）→ ADX 衝高到 35+
亞洲盤 08:00~10:00：27,210~27,294（84pt 區間）
→ ADX 從 35 慢慢回落到 23，但回落速度跟不上盤整的開始
```

**結論：ADX(14) 在 3分K MNQ 上不太適合當作盤整過濾工具。** 它的滯後性讓它無法及時反應盤整開始。

## ✅ 替代方案

### 方案 A：看 DI+ 與 DI- 的關係（取代 ADX 絕對值）

ADX 絕對值沒用，但 **DI+ 和 DI- 的相對關係** 有用：

| DI+ vs DI- | 狀態 | 建議 |
|-----------|------|------|
| **DI+ > DI- 且差距 >10** | 🟢 多頭有動能 | 可以做多，KDJ 金叉可靠 |
| **DI- > DI+ 且差距 >10** | 🟢 空頭有動能 | 可以做空，KDJ 死叉可靠 |
| **DI+ 和 DI- 接近（差距 <5）且交錯** | 🔴 盤整中 | 降低口數，不追 momentum |
| **DI+ 和 DI- 寬幅來回交叉** | 🔴 假突破頻繁 | 不交易或只在區間極端 |

**如何看**：TradingView ADX 指標預設就會顯示 DI+（綠線）和 DI-（紅線）。只要看這兩條線是「分開」還是「糾纏」就好。

**4/29 驗證**：

| 時間 | DI+ / DI- | 判斷 |
|------|-----------|------|
| 08:55 | DI+ 和 DI- 寬幅交叉中 | 🔴 盤整 |
| 09:12 (反彈中) | DI+ 開始拉開差距 | 🟡 但還不穩定 |
| 09:43 | DI+ 明顯 > DI- | 🟢 短線多頭動能 |
| 10:20 | DI+ 29.36 > DI- 15.68，差距 ~14 | 🟢 多頭方向還在 |

### 方案 B：15分K 方向過濾（仍有效）

> **3分K 進場前，先看 15分K 的 KDJ 方向** — 這個規則仍然成立，跟 ADX 無關。

```
3分K golden cross
    └─ 15分K J 在上升 ⬆️ → ✅ 可以進
    └─ 15分K J 在下降 ⬇️ → ❌ 等，這是反彈不是反轉

3分K death cross
    └─ 15分K J 在下降 ⬇️ → ✅ 可以進
    └─ 15分K J 在上升 ⬆️ → ❌ 等，這是回調不是反轉
```

### 方案 C：Bollinger Bands 寬度（BB Width）

Bollinger Band 寬度是更好的盤整判斷工具：
- BB 通道窄化 = 擠壓/盤整中
- BB 通道擴張 = 波動放大/有趨勢

TradingView 可安裝 `BB Width` 或 `Bollinger Bands Squeeze` 指標。
（這個留待後續驗證，目前先從 DI+/DI- 和 15分K 方向過濾開始。）

## 🎯 最終建議（v2 修正後）

### 現在就能用的兩層過濾

```
層級 1️⃣ 看 DI+ vs DI-（同一根 3分K 圖表）
  DI+ > DI- 且拉開差距 → 🟢 偏多，可以考慮做多
  DI- > DI+ 且拉開差距 → 🟢 偏空，可以考慮做空
  DI+ ≈ DI- 或頻繁交叉 → 🔴 盤整，降為 1口或休息

層級 2️⃣ 看 15分K KDJ 方向
  確認 3分K 信號跟大方向一致

層級 3️⃣ 看 3分K golden/death cross → 進場
```

### ADX(14) 的定位

- ❌ 不要用 ADX 絕對值判斷盤整（3分K MNQ 不適用）
- ✅ 可以看 ADX 正在上升還是下降 — ADX 從高檔往下掉 = 趨勢減弱
- ✅ 可以看 DI+/DI- 的差距 — 這才是真正有用的資訊

## 盤整日的特徵（經驗識別）

以下現象同時出現 = 盤整日（**這組清單仍然有效**）：

1. **價格在 60~100pt 區間來回，無法突破**
2. **KDJ 超賣→超買往返 ≥ 2 輪**
3. **EMA 三線糾結（差距 <10pt）**
4. **沒有突破前高/前低，不斷假突破**
5. **成交量偏低**

如果 3 個以上特徵同時出現，今天就是盤整日。
