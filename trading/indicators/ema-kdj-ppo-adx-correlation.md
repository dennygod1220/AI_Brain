## 🔍 關鍵發現 1：PPO 收斂 = 最重要的先行指標

### PPO 線與訊號線的關係

> **PPO 兩線「收斂到同值」時，KDJ 下一次交叉就會有效。**
> **PPO 兩線「差距拉開」時，KDJ 交叉容易失敗。**

**實證：**

| 時間 | PPO/訊號 | 差距 | 接下來發生 |
|------|----------|:----:|-----------|
| 08:55 | -0.00/0.06 | **0.06** | 死叉發展中，J 5→16→3 → 反彈失敗 ❌ |
| **09:12** | **-0.03/-0.03** | **0.00** ✅ 收斂 | **金叉成立，反彈+33pt 成功 🟢** |
| 09:43 | 0.01/-0.00 | 0.01 ✅ 接近 | 金叉維持，價格站上EMA |
| **10:02** | **0.00/-0.00** | **0.00** ✅ 收斂 | **死叉成立，價格回跌 🔴** |
| 10:20 | 0.02/0.01 | 0.01 | 金叉發展中 |

**規律：**
- PPO 和 Signal 差距 **接近 0** → KDJ 交叉信號可靠度最高
- PPO 和 Signal 差距 **> 0.03** → KDJ 交叉容易失敗

## 🎯 結論：四指標趨勢發動 vs 盤整對照表

### 趨勢發動時（可以做）

| 指標 | 特徵 |
|------|------|
| **PPO** | 🥇 **PPO 線與訊號線收斂到接近同值（差距 ≤ 0.01）** |
| **KDJ** | 🥇 **金叉/死叉出現 + 上項 PPO 收斂成立** |
| **DI+/DI-** | 🥈 差距 > 10，明確方向，不頻繁交叉 |
| **EMA** | 🥉 價格站上/跌破三線，且三線斜率同向 |
| **J 值** | 🥉 J 在 oversold 或剛從 oversold 回升/從超買回落 |

### 盤整時（降口數或休息）

| 指標 | 特徵 |
|------|------|
| **PPO** | 🚩 PPO 線與訊號線差距大（> 0.03），或來回穿越零軸 |
| **KDJ** | 🚩 金叉後 15-30 分鐘內馬上死叉，反覆發生 |
| **DI+/DI-** | 🚩 差距 < 5，兩條線頻繁交叉（今天沒發生，但若發生就是盤整） |
| **EMA** | 🚩 三線糾結（差距 < 10pt），價格在線上下穿梭 |
| **J 值** | 🚩 -5 到 105 之間快速來回 ≥ 2 輪 |

## ✅ 新版的進場流程（加入 PPO 收斂確認）

```
Step 1️⃣ PPO 收斂了嗎？
  PPO 線 ≈ 訊號線（差距 ≤ 0.01）→ 繼續
  PPO 差距大（> 0.03）→ 等，還沒準備好

Step 2️⃣ DI+/DI- 有方向嗎？
  差距 > 10 → 方向可信
  差距 < 5 或交叉中 → 盤整警訊

Step 3️⃣ 15分K KDJ 方向一致嗎？
  一致 → 繼續
  不一致 → 等

Step 4️⃣ 3分K golden/death cross → 進場
```
